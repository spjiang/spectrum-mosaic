# 拼图服务 WEB 操作手册

本文说明私有化部署后的测区放置、任务提交、正射与 DSM 验收。安装与许可见《拼图服务私有部署操作手册》。

使用 Chrome 或 Edge 桌面版。本机打开 `http://localhost:9080/`，局域网将 `localhost` 换成服务器地址。端口以 `.env` 中的 `FRONTEND_PORT` 为准。

## 1. 账号与数据权限

### 1.1 生产账号

生产作业使用管理员账号。

|  |  |
| --- | --- |
| 用户名 | `admin` |
| 初始密码 | `admin123` |

首次登录后应立即修改密码。下文的数据放置与任务提交均以该账号为准。

### 1.2 目录对照

系统另预置两个受限作业账号，用于按人隔离测区与成果，不作为生产入口。页面填写容器路径，航片放在交付包的 `data` 目录。下表以交付包位于 `E:\spectrum-mosaic` 为例；解压位置不同时，只替换该根目录。

| 账号 | 初始密码 | 页面路径 | 宿主机目录 |
| --- | --- | --- | --- |
| `admin` | `admin123` | 测区 `/data/input/<测区名>`；成果 `/data/output/runs/<测区名>` | `E:\spectrum-mosaic\data\input\<测区名>`；`E:\spectrum-mosaic\data\output\runs\<测区名>` |
| `trial1` | `trial@123456` | 测区 `/data/input/trial1/<测区名>`；成果 `/data/output/runs/trial1/<测区名>` | `E:\spectrum-mosaic\data\input\trial1\<测区名>`；`E:\spectrum-mosaic\data\output\runs\trial1\<测区名>` |
| `trial2` | `trial@123456` | 测区 `/data/input/trial2/<测区名>`；成果 `/data/output/runs/trial2/<测区名>` | `E:\spectrum-mosaic\data\input\trial2\<测区名>`；`E:\spectrum-mosaic\data\output\runs\trial2\<测区名>` |

`admin` 可使用系统配置、用户管理、计算节点等全部菜单。`trial1`、`trial2` 不可见上述菜单，自安装日起约 30 天有效，且不能访问对方目录。三个账号的新建处理、处理记录与拼图影像为同一界面。计算节点同一时间只执行一条任务。

平台不附带样例测区。管理员第一套数据名称为 `测区数据1` 时，页面填 `/data/input/测区数据1` 与 `/data/output/runs/测区数据1`，航片放在 `E:\spectrum-mosaic\data\input\测区数据1`。后续测区更换名称，不得写入已有目录。

### 1.3 预置方案

安装时已配置两套处理方案，可直接用于生产：

| 方案 | 适用 |
| --- | --- |
| 标准全波段 | 输出彩色及全部光谱波段正射与 DSM，作为正式成果 |
| RGB 快速预览 | 仅输出彩色正射，用于检查几何与接缝 |

任务执行期间不要修改方案中的算法参数。

## 2. 作业顺序

### 2.1 提交顺序

全分辨率、多波段处理耗时以处理记录中的进度为准，通常为数小时，不按固定时长安排验收。

1. 按第 4 节将航片置于本次测区目录。平台不接收整夹航片的网页上传。
2. 打开「新建处理」。正式成果选择「标准全波段」；仅检查彩色正射时选择「RGB 快速预览」。
3. 使用 `admin` 登录。输入测区目录与输出目录采用同一测区名，且分别位于 `/data/input` 与 `/data/output/runs` 之下。

任务成功后，在「处理记录」中检视拼图与质量报告，并下载正射和 DSM。需要替换某一地面单元所用航片时，使用「拼接线处理」。具备野外检查点时，使用「精度验收」。

### 2.2 单任务限制

节点上已有任务处于排队或运行时，「开始处理」显示为「已有任务运行中」。该任务不一定出现在当前账号的处理记录中。此时应等待其结束，不要重复提交。

## 3. 登录与界面

### 3.1 登录

1. 打开服务地址。
2. 生产作业输入用户名 `admin`、密码 `admin123`，点击「登录」。仅在需要数据隔离时使用 `trial1` 或 `trial2`。
3. 右上角为当前用户与角色，可查看「关于」或「退出登录」。
4. 测区数据就位后，由「作业管理」进入「新建处理」，按第 5 节选择方案并提交。数据未就位时先完成第 4 节。

### 3.2 菜单

| 菜单 | 用途 |
| --- | --- |
| 处理方案 | 查看「标准全波段」与「RGB 快速预览」。执行中的任务不要改其参数 |
| 新建处理 | 选择方案，并填写本次测区与成果路径 |
| 处理记录 | 任务列表。检视、下载与验收均从此进入 |
| 拼接线处理 | 由已成功的正射复制新记录，替换指定地面单元的航片 |
| 测区管理 | 航片分批入库时使用。单次测区作业不要在此新建测区 |
| 影像查看 | 打开单张 TIF 或 JPG，查看元数据与像元值。不参与拼图 |
| 新建推扫、推扫记录 | 「推扫拼图」分组，处理 FigSpec 推扫高光谱架次，见第 14 节。部署时未开启推扫则不显示 |
| 使用文档 | 平台内的流程与参数说明 |
| 系统配置、计算节点、系统监控、用户管理 | 仅管理员可见。修改数据路径时须保持在 `/data` 之下 |

页面顶部的任务进度可返回该任务的执行页。

## 4. 测区数据目录

页面填写容器路径，必须以 `/data` 开头。不得填写 `E:\`、`D:\` 或 `data\input`。交付包中的 `data` 目录即容器内的 `/data`。

### 4.1 管理员目录

测区名为 `测区数据1`、交付包位于 `E:\spectrum-mosaic` 时：

| 页面字段 | 填写 | Windows 目录 |
| --- | --- | --- |
| `input_dir` 输入测区目录 | `/data/input/测区数据1` | `E:\spectrum-mosaic\data\input\测区数据1` |
| `output_dir` 输出目录 | `/data/output/runs/测区数据1` | `E:\spectrum-mosaic\data\output\runs\测区数据1` |

解压在其他位置时，页面路径不变，只改盘符。解压在 `D:\mosaic` 时，航片放在 `D:\mosaic\data\input\测区数据1`，成果在 `D:\mosaic\data\output\runs\测区数据1`。

### 4.2 拷贝航片与成果位置

航片按原架次整夹拷入 4.1 的输入目录，保留子文件夹。支持 JPG、TIFF。只放入单张影像，或放在 `测区数据1` 文件夹外面，任务无法识别架次。

```bat
xcopy /E /I "D:\航片\测区数据1" "E:\spectrum-mosaic\data\input\测区数据1"
```

输出目录不用事先建立。任务开始后自动增加一层时间戳，成果在该层的 `拼图结果` 中：

```text
E:\spectrum-mosaic\data\output\runs\测区数据1\20261118_174600\拼图结果\
```

下一测区使用新名称 `测区数据2`，页面填写 `/data/input/测区数据2` 与 `/data/output/runs/测区数据2`，航片放在 `E:\spectrum-mosaic\data\input\测区数据2`。不得写入 `测区数据1`。

数据就位后按第 5 节提交。成果优先在页面下载。传输中断时，按任务详情中的时间戳，到上述输出目录取出 `拼图结果`。

### 4.3 受限作业账号

`trial1`、`trial2` 不得使用 4.1 的管理员目录。路径缺少用户名层时，提交将被拒绝。成果目录把 `input` 换成 `output\runs`，规则相同。

| 账号 | 输入测区目录 | 输出目录 | Windows 航片目录 |
| --- | --- | --- | --- |
| `trial1` | `/data/input/trial1/测区数据1` | `/data/output/runs/trial1/测区数据1` | `E:\spectrum-mosaic\data\input\trial1\测区数据1` |
| `trial2` | `/data/input/trial2/测区数据1` | `/data/output/runs/trial2/测区数据1` | `E:\spectrum-mosaic\data\input\trial2\测区数据1` |

## 5. 新建处理

### 5.1 选择方案

提交前确认「处理记录」中无状态为「排队」或「运行中」的任务。

| 方案 | 选用条件 |
| --- | --- |
| 标准全波段 | 需要彩色及各光谱波段。预设为「通用」，不锁定参考格网，不启用调试套色 |
| RGB 快速预览 | 仅检查彩色正射的几何与接缝。预设为「RGB 快速预览」，只输出 Color |

### 5.2 填写并提交

1. 打开「新建处理」。
2. 「标题」可留空。留空时系统以任务号与时间命名。
3. 按上表选择处理方案。在「输入测区目录」「输出目录」填写第 4 节的容器路径。管理员第一套数据为 `/data/input/测区数据1` 与 `/data/output/runs/测区数据1`，末级名称必须一致。
4. 确认航片已位于对应宿主机目录，例如 `E:\spectrum-mosaic\data\input\测区数据1`。系统读取原始分辨率。「处理方案」中的输入输出参数与此处规则相同；每次任务以「新建处理」页面上的路径为准。
5. 「降低分辨率」：正式成果选择「不降低」。「降低到 1/2」或「降低到 1/4」会增大像元、缩短时间，不是全分辨率成果。页面显示「已锁定交付格网」时，按锁定格网出图，此处倍数不生效。
6. 内存、CPU、GPU、显存保持方案带出的值。无可用 GPU 时自动使用 CPU，成果一致，耗时增加。
7. 展开「方案参数摘要」核对：调试套色为关，调试对照目录为空。
8. 点击「开始处理」。

### 5.3 进度

提交成功后，系统在成果目录下新建时间戳子目录，不覆盖既往成果。右侧「处理进度」显示任务号、状态、总进度、当前阶段和预计剩余。页面顶部进度条可回到该任务。处理记录中的「进度」列与此处为同一数值。

总进度按 7 个阶段等权计算，不是按各阶段实际耗时：

（阶段序号 + 本阶段完成比例）/ 7 × 100

阶段内部的匹配、平差等步骤通常不再增加百分比，因此进度会停住，阶段结束后再跳到下一档。

| 阶段 | 开始 | 结束 |
| --- | --- | --- |
| 输入输出 | 0% | 约 14% |
| 影像编目 | 约 14% | 约 29% |
| 空三解算 | 约 29% | 约 43% |
| 密集匹配 | 约 43% | 约 57% |
| DSM 生成 | 约 57% | 约 71% |
| 正射镶嵌 | 约 71% | 约 86% |
| 质量报告 | 约 86% | 100% |

空三解算会长时间停在约 29%，完成后跳到约 43%。正射镶嵌在约 71% 至 86% 之间也会停留较久。这两种停留都是正常计算，不是卡死。

「预计剩余」在阶段刚开始时可能为空或不稳定，不能当作验收时间。指定 GPU 不表示各阶段都使用显卡，像对匹配在 CPU 上执行。

进度不再前进，且页面提示包装进程已退出或 Worker 没有在计算时，使用 5.4 的「清理并续跑」。正常计算中不要停止或删除。立即停止后，当前阶段未写完的结果不保留；已写完的 DSM 与正射仍留在输出目录。

### 5.4 运行控制

运行控制位于该行「操作」→「运行」，或执行页右上角。

| 操作 | 作用 |
| --- | --- |
| 监控 | 打开执行页，查看进度与日志 |
| 暂停 | 当前阶段完成后暂停。随后「继续运行」，不新建输出目录 |
| 继续运行 | 自暂停处继续 |
| 继续 | 状态为「等待继续」时进入下一阶段 |
| 立即停止 | 立即结束进程 |
| 失败重试 | 自失败处重试，不新建输出目录 |
| 清理并续跑 | 仅在进度停滞且页面提示进程已退出时使用。正常计算中不要使用 |

任务失败时，先在「任务详情」中确认停止的阶段与日志，再决定是否重试。不要通过反复修改方案来提交同一测区。

## 6. 处理阶段与成果

### 6.1 处理阶段

任务按以下七个阶段执行。

| 阶段 | 名称 | 产出 |
| --- | --- | --- |
| 1 | 输入输出 | 校验读写路径并建立本次输出目录 |
| 2 | 影像编目 | 清点航片，剔除白板、贴地及倾角过大的影像 |
| 3 | 空三解算 | 解算影像位置、姿态及稀疏地面点 |
| 4 | 密集匹配 | 在重叠区域估计地面高程 |
| 5 | DSM 生成 | 剔除尖刺、填补小空洞，输出地形 |
| 6 | 正射镶嵌 | 按地形纠正并镶嵌各波段正射 |
| 7 | 质量报告 | 汇总精度与覆盖，输出 PDF |

### 6.2 成果文件

正射与 DSM 位于本次输出目录的 `拼图结果/`。彩色正射为 `Orthomosaic_pix_surf_group0.tif`，其余波段按波长升序为 `group1`、`group2`……地形为 `DSM.tif`。质量报告 PDF 位于输出目录，不在 `拼图结果` 内。

以 S810、8 波段成果为例：

| 文件 | 内容 |
| --- | --- |
| `Orthomosaic_pix_surf_group0.tif` | 彩色正射 |
| `Orthomosaic_pix_surf_group1.tif` | 450 nm |
| `Orthomosaic_pix_surf_group2.tif` | 550 nm |
| `Orthomosaic_pix_surf_group3.tif` | 650 nm |
| `Orthomosaic_pix_surf_group4.tif` | 720 nm |
| `Orthomosaic_pix_surf_group5.tif` | 750 nm |
| `Orthomosaic_pix_surf_group6.tif` | 800 nm |
| `Orthomosaic_pix_surf_group7.tif` | 850 nm |
| `DSM.tif` | 数字表面模型 |

其他测区波长不同时，彩色仍为 `group0`，其余仍按波长升序编号。波段数量变化时，文件数量相应变化。

## 7. 成果检视与下载

### 7.1 处理记录

在「处理记录」中：

1. 可按任务号、状态、阶段、处理方案、日期和关键字筛选。下载正式成果时将状态设为「成功」。
2. 点击该行最右侧「操作」。
3. 按需进入下列功能。

| 操作 | 内容 |
| --- | --- |
| 任务详情 | 七个阶段、分阶段耗时、输入输出路径、运行日志。在「正射镶嵌」中可查看彩色与各光谱波段的耗时 |
| 拼图影像 | 按波段浏览整幅正射，支持平移、缩放，并可下载该波段 GeoTIFF |
| 质量报告 → 查看 | 打开汇总页，并可在页内阅读 PDF。其中的影像定位差来自空三，不是野外检查点精度 |
| 质量报告 → 下载 | 下载质量报告 PDF |
| 下载 → 处理参数 | 下载本次任务实际采用的参数 |
| 下载 → 拼图原文件 | 将各波段正射与 DSM 打包为 zip |
| 精度验收 | 在正射上布设检查点并填入野外坐标后评估 |
| 监控 | 任务运行中打开执行页 |

列表中的 RGB 缩略图仅用于辨认任务。正式交付的整幅正射、各光谱波段和 DSM，使用「拼图原文件」或拼图页中的下载。

### 7.2 拼图影像

在「拼图影像」中：

- 以「波段」切换彩色与各光谱波段。
- 「下载当前波段原文件」仅下载当前 GeoTIFF，按钮标注文件大小。
- 「下载全部文件」包含各波段正射、DSM 与质量报告。

浏览结束后点击「返回记录」。文件较大、浏览器传输中断时，按任务详情中的输出路径，在交付包 `data/output/runs/` 下取出 `拼图结果/`。

## 8. 质量报告

### 8.1 查看与下载

任务成功后，在「操作」→「质量报告」中选择「查看」。

页面可在「汇总」与「PDF」之间切换。汇总包含空三、DSM、正射及各相机统计，以及正射、DSM、相机位置、空三、重叠度等图件。点击「下载」获得 PDF。

### 8.2 指标含义

「特征点」为单张影像上提取的纹理位置。「连接点」为多张影像匹配后的同名点，不是特征点本身。影像定位差来自空三，不能代替第 9 节的野外检查点。

## 9. 精度验收

### 9.1 布点与评估

具备野外实测坐标时进行。无野外点时，以质量报告作为内部质量说明。排队中的任务不能验收。

1. 在成功任务的「操作」中打开「精度验收」。
2. 核对「最少点数」「最多点数」和「平均位置误差上限」。默认为 20 至 30 个点，平均误差须小于 2 像素。修改后点击输入框以外的位置以保存。
3. 「基准波段」选择布点所用正射，一般使用彩色。
4. 「野外坐标系」：经纬度选择 `EPSG:4326`；野外坐标已为拼图所用投影坐标时，选择页面列出的对应坐标系。
5. 保持「添加检测点」。在主视图单击明显地物。左侧缩略图仅用于跳转，不用于布点。按住拖动平移，滚轮或「放大」「缩小」调整比例。
6. 在表格中填写该点的野外经度、纬度，或东、北坐标。离开该单元格时保存。
7. 点数落在上下限之间后，点击「评估校验」。

结果按点显示「满足」「不满足」「未完成」或「未评估」。像素误差为拼图坐标与野外坐标的平面距离除以基准波段地面分辨率，再对各点取平均。

### 9.2 修改点位

点位有误时，先选中该行，再点击「移动选中点」，然后在主视图上指定新位置。不需要的点在该行点击「删除」。

## 10. 拼接线处理

### 10.1 新建记录

需要将某一地面单元改用另一张重叠航片时使用。源任务成果不被修改。系统复制成果，并生成带「拼接线」标记的新记录。

1. 打开「拼接线处理」。
2. 点击「新建拼接线处理」，选择一条已成功、且本身不是拼接线任务的任务号，点击「创建」。
3. 在新记录上点击「处理」。
### 10.2 改片与重算

4. 使用「放大」「缩小」「适应」查看。在图上拖动可平移。
5. 点击一块自动分区，右侧列出覆盖该单元的航片。选择另一张即完成替换。
6. 需要手工划定范围时，点击「绘制范围」，在图上依次点击，至少 3 点后点击「闭合」。可「撤销一点」或「取消绘制」。
7. 确认右侧「已用于这块」的航片后，点击「重算」。未作修改时「重算」不可用。
8. 返回「处理记录」，待新任务成功后按第 7 节下载。

「放弃修改」丢弃尚未出图的手工选择。已按手工范围出图时，将再生成一版由软件自动选片的结果。任务运行中不能进入处理界面。

## 11. 分批入库

### 11.1 收件区

仅在航片分批到达、需要持续收片时使用「测区管理」。单次测区作业按第 4、5 节执行，不要在此新建测区。

测区建立后，正式目录与输出根目录不可再改。收件区为正式目录加后缀 `.inbox`，页面「上传命令」可复制。

1. 打开「测区管理」，进入目标测区。
2. 按页面命令将新航片传入收件区。同一曝光号的替换片，或后到的新波长，均传入收件区，不要直接写入正式目录。
### 11.2 入库与拼图

3. 同一文件连续两次扫描大小不变后，视为传输完成并拷入正式目录。可点击「立即扫描入库」，或等待页面上的扫描间隔。
4. 「入库后自动拼」开启时，新航片入库后在该任务上开始拼图。关闭时只入库，数据齐套后再点击「在当前任务上拼图」。
5. 其他任务运行期间，新文件可以入库，本任务须待其结束后再开始。拼图进行中不会另开第二条任务。

曝光列表中：「上传中」表示文件大小仍在变化，「已传完」表示可以入库，「已入库」表示已进入正式目录。

删除测区只删除该条记录。正式目录、收件区与已有成果文件均保留。

## 12. 单张影像查看

### 12.1 打开与查看

「影像查看」用于核对单张 TIF 或 JPG，不参与拼图。

将文件拖入页面，可查看元数据、波段及点击位置的像元值。视图为抽样预览，不是全分辨率浏览。

## 13. 作业约束

### 13.1 任务运行

- 不要删除或停止正在运行的任务。删除只从列表移除记录，成果仍保留在 `data/output`。
- 任务运行期间不要修改「标准全波段」和「RGB 快速预览」的算法参数。
- 不要并行提交第二条任务。
- 进度正常推进时，不要使用「清理并续跑」或「立即停止」。

### 13.2 数据与成果

- 受限作业账号的测区与成果必须位于该账号根目录之内。
- 不要将列表中的 RGB 缩略图作为正式正射成果。
- 单次测区作业不要新建测区，也不要开启「入库后自动拼」。

## 14. 推扫拼图

推扫拼图处理 FigSpec 推扫高光谱相机的原始 DN 数据，与上面的框幅航片拼图互不影响，由单独的推扫计算服务执行。菜单在「推扫拼图」分组下。看不到该分组时，部署未开启推扫，见《拼图服务私有部署操作手册》第 6 节。

### 14.1 放置架次

一次飞行是一个架次目录，名称形如 `FigSpec_260419_132008`，内含 `figspec.hdr`、`figspec.spe`、`figspec.gps` 三个文件。整夹拷贝，不要改文件名，不要只拷部分文件。

| 账号 | 架次放在 | 成果写到 |
| --- | --- | --- |
| `admin` | `/data/input/pushbroom/<架次>` | `/data/output/pushbroom/<架次>/<时间戳>` |
| `trial1`、`trial2` | `/data/input/<用户名>/<架次>` | `/data/output/runs/<用户名>/pushbroom/<架次>/<时间戳>` |

Windows 上 `admin` 的架次即 `E:\spectrum-mosaic\data\input\pushbroom\<架次>`。

### 14.2 新建推扫

1. 打开「新建推扫」。「选择架次」列出上述目录下的全部架次，标「可提交」的才能处理。
2. 选中架次后，「核对结果」显示影像尺寸、数据量、波长范围、定位与成果分辨率。标「不可用」时按提示补齐文件。
3. 「拼图参数」：
   - 地面分辨率：默认「自动（按航高和相机估算）」，一般不改。
   - 输出波段：默认全部波段。只看几何或接缝时可「指定波段」，填波段序号，例如 `30,60,90`，处理快、成果小。
4. 填写任务名称后提交。

### 14.3 推扫记录与成果

「推扫记录」显示进度、各步耗时、运行日志，任务结束后列出成果文件，可直接下载。成果文件：

| 文件 | 内容 |
| --- | --- |
| `<架次>_mosaic.spe` / `.hdr` | 镶嵌后的高光谱立方体（ENVI 格式，带地理坐标），正式成果 |
| `<架次>_rgb.tif` | 真彩色合成 GeoTIFF，原始 DN（16 位）。GIS 默认打开会偏暗，分析用 |
| `<架次>_rgb_display.tif` | 显示用 8 位 RGB（已拉伸），给人看、进 GIS 浏览 |
| `<架次>_preview.png` | 预览图，与显示 GeoTIFF 同一套拉伸 |
| `<架次>_footprints.geojson` | 各航带覆盖范围 |
| `report.md` / `report.json` | 质量报告：航带、配准、精配准、传感器标定自检 |

质量报告「传感器标定自检」出现加粗警告时，说明相机安装参数与当前标定不符（常见于重装相机后）。成果仍可用，但航带间会有错位，请按部署手册第 6.3 节重新标定。

### 14.4 精度说明

成果绝对位置以机载单点 GPS 为准，航带之间残余错位约 0.2～0.4 米；同一块区域内经精配准后错位中位约 0.15 米。需要更高绝对精度时，须使用 RTK 定位数据或地面控制点，联系供应商。
