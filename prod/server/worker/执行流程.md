# 多光谱拼图执行流程

当前实现：`POS 直接地理定位 + 北向上重投影 + merge`。  
入口：`./run.sh` → `python -m ms_mosaic` → `run_mosaic()`。  
原始 `MAX_*` 目录只读，成果只写 `--output-dir`。

## 总流程

```mermaid
flowchart TB
  start["./run.sh"] --> cli["python -m ms_mosaic"]
  cli --> guard{"--output-dir 是否落在输入目录内"}
  guard -->|是| stop["报错退出，不写任何文件"]
  guard -->|否| scan["扫输入目录<br/>认 MAX_* 文件名"]

  scan --> parse["按编号捆成一次曝光<br/>Color JPG + 7 个波段 TIF"]
  parse --> pos["从每张图内部读 POS<br/>EXIF GPS + XMP 航向/航高"]
  pos --> filt{"过滤"}
  filt -->|"白板 _W / AGL&lt;5m / 无 POS"| drop["丢弃，不写盘"]
  filt -->|作业帧| loop["逐曝光处理"]

  loop --> rgb["RGB: 按 POS 落到地图"]
  loop --> ms["各光谱: 各自 POS 落到地图"]
  rgb --> proc["写出 out/process/<br/>0003_rgb.tif 等"]
  ms --> proc
  proc --> mergeRgb["merge 全部 RGB 帧"]
  proc --> mergeMs["每个波段分别 merge"]
  mergeRgb --> mosaics["out/mosaics/rgb.tif"]
  mergeMs --> mosaics2["out/mosaics/ms_450nm.tif … ms_850nm.tif"]
  mosaics --> report["out/report/quality.md<br/>out/log/run.json"]
  mosaics2 --> report
```

## 单帧如何落到地图（process/ 里的 GeoTIFF）

```mermaid
flowchart LR
  img["原始 JPG / TIF<br/>无地理坐标"] --> gsd["用 AGL 和焦距估 GSD<br/>约 5 cm"]
  img --> gps["经纬度 → UTM<br/>EPSG:32647"]
  img --> yaw["用 Camera Yaw 旋转像素轴"]
  gsd --> affine["图中心钉在 GPS 点<br/>得到带旋转的仿射"]
  gps --> affine
  yaw --> affine
  affine --> warp["reproject 成北向上网格"]
  warp --> geotiff["process/00xx_*.tif"]
```

地面按水平面处理，不用 DEM，也没有空三。

## 镶嵌（mosaics/ 里的大图）

```mermaid
flowchart TB
  frames["同一通道的多张北向上 GeoTIFF"] --> merge["rasterio.merge"]
  merge --> overlap{"重叠像元"}
  overlap --> last["后到的帧覆盖先到的帧<br/>无羽化、无拼接线"]
  last --> out["mosaics/ 下该通道一张大图"]
```

RGB 和 7 个光谱是 8 次独立镶嵌，波段之间不做特征配准。

## 目录对应关系

```text
--input-dir  MAX_20251017_001/ 只读原始影像
--output-dir
  process/                     中途：每一曝光、每一通道的正射单帧
  mosaics/                     结果：拼好的 RGB + 7 个光谱大图
  report/quality.md            人看的摘要
  log/run.json                 同样内容的日志
```
