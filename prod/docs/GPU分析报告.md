# GPU 分析报告

2026-11-03 在线上验证机上重测。机器是 2 张 Tesla T4，正式计算用 32 个 CPU 核。数据是 S810 架次 1530 的全部原始影像：249 个曝光、1992 张、8 个波段，不是抽样，也不是合成图。

界面上的「任务 GPU」只表示提交时选了哪张卡。下面除了写明「一张 T4」的步骤，正式路径都在 CPU 上。

一张卡要缩短墙钟，得超过 32 个核一起算。只比一个核快，整段任务仍然不会变短。25 分钟是客户现场 RTX 4090 的目标，这里的时间都是 T4，不能换算过去。

## 各节点在做什么

CPU 耗时、GPU 耗时都是墙上时间。GPU 一栏写「—」表示这一步没有在 T4 上跑完。选用按整段任务的墙钟，不按单核对比。

| 节点 | 作用 | CPU 耗时 | GPU 耗时 | 选用 | 技术原因 |

| 路径校验 | 确认 1993 个输入文件都在 | 0.006 秒 | — | CPU | 只做文件系统查询。数据不进显存，显卡没有对应指令 |
| 影像编目 | 解析文件名和定位旁路，把 249 个曝光的各波段归组 | 1.5 秒 | — | CPU | 分支判断和读小文件。计算量是文本解析，不是规则的大矩阵乘法 |
| 影像筛选 | 按航高、倾斜、白板剔除曝光。这批 249 个全部留下 | 0.005 秒 | — | CPU | 249 条记录的阈值比较。启动一次 GPU 内核的开销已经大于全部计算 |

## 像对匹配

这一步回答「两张相片里哪些点是同一个地面点」。32 个核做近似最近邻，一张 T4 做精确最近邻，几何校验都是 32 个进程上的 MAGSAC。

同一批 10917 对：

| | 墙钟 | 成功像对 |
| --- | ---: | ---: |
| 32 核近似匹配 | 508 秒 | 10468 |
| 一张 T4 精确匹配 | 2338 秒 | 10481 |

单卡大约慢 4.6 倍。成功条数同一量级。更早一次全流程也是 508 秒对 2339 秒，整次任务 2.2 小时对 2.9 小时，重投影都在 0.57 像素附近。卡当时大约 60% 在忙，墙钟仍然更长。匹配因此固定走 CPU。

## 密集匹配

这一步把稀疏的连接点变成每个地面格子的高程。先在粗格网上把高程大致定住，再在细格网上收窄范围重算。

整段 1203 秒是这批数据在 32 核上跑完粗格网和细格网的时间。代码里没有整段 GPU 密集匹配，今天没有把 323 块再跑一遍。

用这批影像的真实像素、按正式块大小测了两个内核：

| 内核 | 单核 | 一张 T4 |
| --- | ---: | ---: |
| 窗口相关，384×384 | 0.025 秒 | 0.003 秒 |
| 半全局聚合，48×384×384 | 6.86 秒 | 0.27 秒 |

单卡都比单核快。和 32 个核比，同样一段单核时间里，窗口相关 32 核能做 32 次、单卡大约做 8 次；半全局聚合 32 核能做 32 块、单卡大约做 25 块。半全局聚合必须沿扫描线一格接一格算。整段 1203 秒里还有读图和逐层投影。

## 正射

重采样把相片贴到地图上。拼接线决定重叠的地方用哪一张，避免一条缝切过房子。增益把彩色影像的亮度拉齐。多光谱不再各算一遍几何，拼接线在参考波段上算一次，其余波段沿用。

真实影像的中心一块：重采样单核 7.5 秒、单卡 0.5 秒，图割 5.5 秒。单卡把贴图加快了，图割还在 CPU 上。

整幅 Color 是 1221 块，用的是这次任务的真实 DSM 和真实相片：

| | 进程 | 墙钟 |
| --- | ---: | ---: |
| 重采样和图割都在 CPU | 32 | 339 秒 |
| 重采样交给一张 T4，图割仍在 CPU | 8 | 398 秒 |

8 进程是显卡还能接重采样的上限。再多，每个进程都要在卡上占一个位置，T4 会被排队拖住。这次 8 进程开 GPU 比 32 核纯 CPU 慢 59 秒。少了的 24 个核本来在并行做图割和读图，单卡省下的贴图时间补不回来。

## 其余节点为什么换 GPU 没有空间

路径校验、编目、筛选、候选像对、连接点、写 DSM、质量报告，全量加起来不到 1 分钟，时间在读目录、串轨迹和写文件。

前方交会的 79 秒是 183 万个点的实测。把这批矩阵的批量 SVD 交给 CuPy 时，库要求 `libcublas.so.12`，验证机上的 CUDA 是 11，只有 `libcublas.so.11`，这一调用起不来。

平差是稀疏方程反复迭代。阶段 1、阶段 2 各约 9 到 10 分钟，是这批数据任务日志里的整段时间。没有 GPU 平差可跑。阶段 3 已关闭。

特征提取 233 秒是 1992 张全部重算的结果。没有可以运行的 GPU SIFT。

## 和 25 分钟目标

这批全量数据里，特征、匹配、交会、平差、密集匹配、正射加起来已经超过 1 小时。匹配改上单卡会从 508 秒变成 2338 秒。正射在允许使用显卡的 8 进程下，整幅比 32 核慢。其余节点的全量时间本身就很短，或者没有能在这张 T4 上跑起来的实现。

这些时间不能用来推 RTX 4090 能不能到 25 分钟。
