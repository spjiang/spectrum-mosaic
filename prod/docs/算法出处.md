# 算法出处（禁止无文献的自创主路径）

每条都能在论文、经典教材或开源摄影测量实现里对上。改主路径前先查这里；没有出处就不要换算法。2026-09-26 的验收停点与不要再试的改法见 `验收停点.md`。

| 环节 | 做法 | 出处 |
| --- | --- | --- |
| 特征 | SIFT | Lowe, *Distinctive Image Features from Scale-Invariant Keypoints*, IJCV 2004 |
| 特征 | RootSIFT（L1 归一化再开方） | Arandjelović & Zisserman, CVPR 2012；COLMAP / OpenSfM 默认描述子 |
| 匹配 | kNN + ratio test | Lowe, IJCV 2004 |
| 匹配 | FLANN kd-tree | Muja & Lowe, VISAPP 2009 |
| 几何校验 | 本质矩阵 5 点 + RANSAC | Nistér, PAMI 2004；Fischler & Bolles, CACM 1981 |
| 像对预筛 | POS 足迹重叠，不用词袋 | GNSS/INS-Assisted SfM, *Remote Sens.* 2020, 12(3):351 |
| 多光谱空三 | 八组各自提特征、组内选对与匹配，多相机联合 BA；密集/DSM 仍只用主波段 Color | LiMapper 质量报告（本测区八组特征/连接点/标定）；OpenSfM multi-camera；COLMAP multi-camera BA |
| 空三策略 | GNSS/INS 作外方位初值，不做增量 SfM | 同上 12(3):351 |
| 碗状变形 | GNSS 进法方程 + 分阶段释放畸变 | *Remote Sens.* 2021, 13(21):4222 |
| 相机 | Brown–Conrady + 仿射 b1/b2 | Brown, Photogrammetric Engineering 1966；与 LiMapper 报告 10 参数表一致 |
| 平差 | Huber 核重投影 + Schur 补稀疏 LM。组内选对使各波段法方程块对角，按波段并行分解，方程与整块求解相同；并行路数按任务内存与剩余内存封顶，分批组装避免多路法方程同时驻留 | Triggs et al., *Bundle Adjustment — A Modern Synthesis*, 1999；Ceres / COLMAP |
| 交会内存 | 只加载关键点坐标、匹配构轨后释放像对与描述子；交会方程仍为多视 DLT，与 COLMAP/OpenSfM 前方交会一致，不改数值路径 | Hartley & Zisserman, *Multiple View Geometry* DLT；COLMAP `EstimateTriangulation` 仅用观测坐标 |
| 外点阈值 | 6 px | 本测区 LiMapper 质量报告原文 |
| 密集匹配 | 物方平面扫描 2.5D | Collins, CVPR 1996；Gallup et al., CVPR 2007；LiMapper「类型 2.5D」 |
| 分层立体 | 先 4×GSD 宽窗定位（±24 m），再成品格网 ≥±4 m 精化；细层半宽不得塌成粗层一个步长 | Gallup et al., CVPR 2007；Scharstein & Szeliski, IJCV 2002；架构 §4.5 |
| 代价聚合 | SGM 两级惩罚 p1/p2 | Hirschmüller, PAMI 2008 |
| DSM 去噪 | 邻域中值 + MAD 去尖，再 3 格中值平滑 | Kraus《Photogrammetry》；稳健统计常规；与商业 DSM 比对验收 |
| DSM 补洞 | 足迹域内调和插值（小洞 Laplace）+ 最近邻（大缺口 EDT） | Press *Numerical Recipes* 调和插值；Kraus《Photogrammetry》正射覆盖取相片足迹；Burrough & McDonnell, *Principles of Geographical Information Systems* 最近邻 DEM 填空 |
| 真正射 | DSM 逐格反投；正射高程重采样按有效权重归一（nodata 不参与）；贴边 80 m 内改用 40 m 块平均面；归一化半径超出像幅四角 1.15 倍的射线判无效 | Kraus《Photogrammetry》；Amhar et al. 1998。Brown, PE&RS 1966 畸变只在像幅内成立。本测区两处边缘错误：k 在半径 1.88 回折，把 300 m 外的地面折进像幅；高程重采样把 nodata 当 0，北缘权重 0.5 时高程从 1790 m 掉到 899 m，拉出竖条 |
| 遮挡 | Z-buffer（物方点投到像方取近） | Amhar et al. 1998；Habib et al., *Remote Sens.* 2018, 10(4):581 |
| 最大倾斜 | 60° | LiMapper 报告「最大倾斜角」 |
| 拼接线 | 图割 α-expansion | Boykov, Veksler, Zabih, PAMI 2001；Kwatra et al., SIGGRAPH 2003；Li et al., ISPRS JPRS 2016 |
| 曝光增益 | 重叠区灰度最小二乘（全局，禁止按块）；解完后中位置 1 再裁剪 | Brown & Lowe, IJCV 2007 *Automatic Panoramic Image Stitching* |
| 融合 | 拉普拉斯金字塔 | Burt & Adelson, ACM TOG 1983 |
| 颜色校正 | RGB 全图 Brown & Lowe 分通道增益（禁止按块）；多光谱不加增益 | Brown & Lowe, IJCV 2007；商业样例对本测区写「颜色校正：禁用」指多光谱/花哨调色，不是禁止曝光补偿 |
| 块拼接 | 重叠带加权（Szeliski 羽化） | Szeliski, *Image Alignment and Stitching: A Tutorial*, FnT 2006 §6 |
| 格网 | 正射 GSD = 中位航高 / f_px，DSM = 2×正射；足迹铺画幅 | Kraus《Photogrammetry》GSD=H/f；正射=DSM/2 为行业比例 |
| 格网参考面 | GSD/足迹用「按面积加权的稳健地形面」：稀疏点落 10 m 粗格网取中值（一格一票），再对占用格网取均值 | Kraus《Photogrammetry》平均 GSD 取块平均地面高程。点数中位数给 1691.3 m，本法给 1725.1 m，与商业 DSM 足迹内面均高 1730.9 m 只差 5.8 m |
| 格网锁定 | 交付规格由任务书给定时，直接取参考成果的 GSD/原点/宽高（`grid_reference`），不由影像反推 | 工程规格约束，非算法。自动估计 GSD 偏粗 13%、原点差半像元，未锁定时逐像元比对量的是格网错位 |
| 辐射归一化 | 按参考成果做分位数匹配的全局仿射（每波段 gain/offset），不动纹理与局部对比 | Hall et al., *Remote Sensing of Environment* 1991 相对辐射校正；Chavez, *RSE* 1988 暗目标减法同族。实测本测区映射为 R 0.9418x−13.66 / G 0.9612x−18.46 / B 0.9656x−18.17，分位残差 18–23 → 0.9–1.7 DN |
| 覆盖域 | 相片足迹并集 + 闭运算修边 + `edge_trim_m` 从外缘往里收。RGB 全 0 当孔（小孔补、大洞透明）。禁止套参考 alpha | Kraus 正射覆盖取足迹。商业不交最外单视斜视。本测区右上两处（674607,2620470 / 674602,2620222）在商业轮廓外 7–19 m，模版收边 20 m。套参考 alpha 曾把未采样格标成不透明黑（有效区 3.7%，商业同类阴影 0.5%） |
| 高程搜索 | 半宽由稀疏点 p90−p10 的 1/4 估计（夹在 8–48 m） | Gallup et al., CVPR 2007；随地形起伏变，不写死 12/24 m |
| RGB 低频套色 | 调试开关，不进合格主路径 | Burt & Adelson, ACM TOG 1983。主路径只用 Brown & Lowe 增益 |
| 验收 | `--benchmark-dir` 只写比对报告，不改出图 | `ms_mosaic.compare.write_delivery_report` |

本测区验收样例（`MAX_20251017/拼图结果/`，不是系统默认值）：

- CRS：EPSG:32647
- DSM：6590×5957，GSD 0.10774729333596 m，float32，nodata −3.4028235e+38，LZW，**非 tiled**，interleave=band
- RGB group0：13179×11913，GSD 0.053873647004366 m，uint8×4（RGBA），LZW，**非 tiled**，interleave=pixel
- MS group1–7：同 RGB 格网，uint16×1，nodata=None，0 表示无效，interleave=band
- 正射原点相对 DSM 原点偏移 **半个正射像元**（约 0.02694 m）
- 辐射档位：R/G/B 均值 49.1 / 91.1 / 65.2，p99 = 148 / 196 / 164，**饱和率 0**。源 JPG 为 53.6 / 107.4 / 82.3（饱和 0.16%），即商业成品减掉了约 14.5 / 19.2 / 18.8 DN 的暗电平
- 高程：p1/p50/p99/max = 1651.1 / 1721.3 / 1812.3 / 1830.2 m。稀疏点只到 p99=1798.0，比商业 p99 低 14 m，先验面在最高 4% 地面上低 45.8 m

## 商业拼图经验（抽成通用参数，不抄成品）

对标 `拼图结果/` 是为了得到可换测区的模版项，不是把商业掩膜/像素搬进成果。

| 经验 | 通用做法 | 本测区模版 |
| --- | --- | --- |
| 交付格网由任务书给定，不要用航高反推去和成品逐像元比 | `grid_reference` 只锁 GSD/原点/宽高 | `/data/input/MAX_20251017/拼图结果` |
| 成品亮度是减暗电平后的仿射档位，不是伽马 | `radiometric_normalize` + `benchmark_dir` 作档位参考 | `true` |
| 不交像幅外的回折射线；错误 DSM 上真正射比平面正射更差 | 覆盖取足迹，默认不收边；投影时丢掉归一化半径超出像幅的点；贴边 `flatten_edge_win_m` / `flatten_edge_band_m`。本测区商业有效区 35.73 ha > 足迹，收 20 m 只剩 29.96 ha | `0`、`40` / `80` |
| RGB 全 0 必须透明，不能标成不透明黑 | `apply_coverage_mask` 视 RGB0 为孔 | 主路径默认 |
| 地形带、补洞跨度、去尖随测区变 | `terrain_margin_*` / `max_fill_gap_m` / `spike_tolerance_m` | 30 / 50 / 80、40、2.5 |
| `--benchmark-dir` 只写比对报告 | 不改格网、覆盖、颜色（辐射归一化是显式开关） | 同参考目录 |

## 已实测否证的做法（不要再走回头路）

| 试过的改法 | 实测结果 |
| --- | --- |
| 粗层搜索带按地形起伏加宽到 ±50 m（Collins 空间扫描的全范围搜索） | 山顶窗口粗差率 15.4% → 21.9%，成品解出率 56.0% → 39.3%。宽带里多出的层给了假匹配更多机会 |
| 补洞改解「残差 + 空三趋势面」（带漂移项的插值） | 山顶窗口中误差 5.20 → 119.3 m。空三飞点被先验面的核回归摊开了 |
| 交付覆盖改按视角重数门限（≥2/3/…） | IoU 在门限=1 时最高（0.862），越严越低；覆盖面积占比 0.738 已与商业 0.740 一致。覆盖规则本来就是对的 |
| 怀疑块界重影（正射按 384 块独立求接缝线） | 列向梯度按 col%384 分相位统计，相位 0 为基线的 0.997×（商业 0.995×），无系统性尖峰 |
| 怀疑最近邻填补造成 Voronoi 色块 | 同值团块占有效区 0.40%，商业 0.61%，商业的最大团块还更大（25640 格 vs 2503 格） |
| 怀疑合理高程带把山顶裁掉 | 两种带（DSM 自身 1591.7–1840.7、空三点 1626.1–1848.0）对商业真地形的裁除率都是 0% |
| 按商业正射 alpha 就地裁自研成果 | 未采样格被标成不透明黑：有效区纯黑 3.70%（581 万格），商业同类 0.50%。黑斑最大团 134 万格。对标只抽参数进模版，覆盖必须由本次足迹 + `edge_trim_m` 自己算 |
| RGB 全 0 当孔后再做 20 m 腐蚀 | 4 连通腐蚀从每个内部小孔往外扩，林内打出满图菱形白洞。内部孔必须先填上，收边只削外轮廓 |
| 把贴边平面写进交付 DSM | 外缘 20/40/80 m 后全幅中误差约 4.77 / 5.45 / 6.50 m，比原 4.42 m 更差。`flatten_edge_z` 只留给真正射采样 |
| 外缘加大中值平滑 | 15/31 格只作用外缘 20 m，全幅中误差仍约 4.42 m |
| 用匀色或接缝去抬正射相关 | 25 块内部窗口最佳对齐后中位相关 0.43、错位中位约 29 像元（约 1.6 m）且方向不一致。相关 0.19 来自高程引起的投影错位，不是亮度 |
