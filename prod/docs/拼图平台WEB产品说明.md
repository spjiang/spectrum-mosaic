# 高光谱拼图平台（Web）产品说明

版本 1.0。本文说明 Web 页面能做什么、谁能用、一次作业怎么走完。

## 1. 产品做什么

把航摄影像处理成正射拼图和 DSM，并给出质量报告。

一次完整处理经过七步：

1. 输入输出：确认读哪里、写到哪里。
2. 影像编目：清点航片，去掉白板、贴地、大倾角废片。
3. 空三解算：求出每张照片的位置、朝向和稀疏地面点。
4. 密集匹配：在重叠区域估计地面高程。
5. DSM 生成：去掉尖刺、补小洞，写出地形文件。
6. 正射镶嵌：按地形把照片压到地图上，拼成正射大图。
7. 质量报告：汇总精度与覆盖，写出 PDF。

成果在任务输出目录的 `拼图结果/`：彩色正射为 `Orthomosaic_pix_surf_group0.tif`，其余波段为后续组号，地形为 `DSM.tif`。质量报告为输出目录下的 `质量报告.pdf`。

## 2. 谁可以使用

登录后按角色看到不同菜单。

| 角色 | 能做的事 |
| --- | --- |
| 系统管理员 | 全部功能，含用户、权限、计算节点和系统配置 |
| 操作员 | 新建任务，暂停、继续、删除任务；可看方案和记录 |
| 配置管理员 | 维护处理方案和系统配置；不能提交或管控任务 |
| 只读用户 | 查看方案、记录、影像和文档；不能改配置、不能提交任务 |

## 3. 建议的使用顺序

1. 配置管理员在「处理方案」里建好参数并保存。
2. 操作员在「新建处理」里选方案、确认测区和输出目录，提交任务。
3. 在「处理记录」里看进度。点流程节点可看该步分项和耗时。
4. 任务成功后，下载质量报告，或打开 RGB 拼图查看。
5. 若要改某一块用哪张照片，用「拼接线处理」，不要在原任务上直接改文件。

## 4. 页面说明

### 作业管理

**新建处理。** 选择处理方案，确认输入测区、输出目录、内存、CPU 和 GPU。提交后生成一条处理记录。没有提交权限的账号只能看进行中的任务。

**处理方案。** 按七个阶段填写参数，可新建、编辑、导入、导出。常用项包括测区路径、波段、空三与正射并行度、RGB 偏色、拼图分辨率倍数、边缘裁剪。质量报告阶段可设置「较差影像下限（点）」和「较差影像均值比例」：特征点少于 `max(下限, 均值 × 比例)` 的影像，会写进报告的「潜在较差影像」。默认 80 和 0.20。只读用户只能查看方案。

**处理记录。** 任务列表。每行有状态、进度、流程、资源占用和时间。操作包括：

- 任务详情：流程、分辨率、输入输出路径和日志。
- 评估：用 GPS 和外方位比较平面偏差，按拼图像素计。
- 下载报告：质量报告 PDF。
- 下载参数：这次任务实际使用的参数，可再导入处理方案。
- 查看 RGB 影像：已有彩色拼图时打开预览，并可下载这张预览图。
- 监控：任务还在跑时，打开执行页看进度和日志。
- 暂停、立即停止、继续运行、失败重试、清理并续跑、删除。删除只从列表移除，成果目录保留。运行中的任务要先停再删。

流程上每个节点的时间，是该步实际跑过的耗时。拼接线任务会带来源任务各步的时间；后来重算的那一步按新的一趟重算，没重跑的步骤保留原时间。

**拼接线处理。** 从一条已经成功的正射任务复制成果，生成独立记录。来源文件不移动、不改写。

在处理界面可以放大、缩小、拖动拼图。点自动色块可换用右侧列出的重叠照片。点「绘制范围」可圈一块地面，闭合后列出能看到这块的全部彩色影像，再指定用哪一张。「重算」按已改的范围重新出正射；「放弃修改」丢掉尚未提交或已写入的手工改动。自己画的范围可以再次点中。

拼接线任务同时出现在「拼接线处理」和「处理记录」里，记录上带「拼接线」标记。

### 辅助工具

**影像查看。** 上传 TIF 或 JPG，查看元数据、波段和像元值。大图为抽样预览。

**使用文档。** 流程、算法和参数说明。

### 系统管理

仅管理员，系统配置还可由配置管理员维护。

**计算节点。** 查看计算服务、当前任务、内存、显卡和进程。

**系统监控。** 查看数据库、消息队列和计算服务是否正常。

**系统配置。** 配置计算环境等运行参数。

### 组织管理

仅管理员。

**用户管理、角色管理、权限管理。** 维护账号、角色，以及各角色能看到的菜单。

**操作审计。** 记录谁改了方案、谁提交或删除了任务。

## 5. 使用时注意

- 处理方案决定算法口径。新建任务用的是提交当时的方案，之后改方案不影响已经在跑的任务。
- 拼接线处理是复制出的新任务。重算正射会保留上一版成果，不覆盖来源任务的文件。
- 「查看 RGB 影像」里下载的是窗口中的预览图，不是整幅 GeoTIFF。
- 质量报告里的「特征点」和「关键点」是同一批点：每张照片上提取的纹理位置，每张最多 8192 个。连接点是多张照片对上之后的点，不是特征点本身。
