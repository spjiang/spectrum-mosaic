# 高光谱拼图平台试用说明

试用地址：[http://10.17.19.198:8080/jobs](http://10.17.19.198:8080/jobs)

用电脑浏览器打开（Chrome 或 Edge）。需要能访问 `10.17.19.198` 这台内网机器。手机上看不了大图。

试用账号由管理员单独提供。登录后左下角会显示当前账号。试用期间不要改系统配置、不要改这个账号的密码、不要删除已有任务。

## 1. 建议先看已有成果

处理记录里已经有跑完的 S810 任务。先看这些，不用马上新开一次。一次全流程大约 2 小时。

1. 打开上面的地址，用试用账号登录。登录后若停在别的页面，点左侧「作业管理」→「处理记录」。
2. 在列表里找状态为「成功」的任务。
3. 点该行「操作」，按下面顺序看：

| 操作 | 能看到什么 |
| --- | --- |
| 任务详情 | 七步流程、每步耗时、输入输出路径、运行日志。点「正射镶嵌」可看 Color 和各光谱波段各花了多久 |
| 查看RGB影像 | 彩色拼图预览。窗口里下载的是当前预览图，不是整幅 GeoTIFF |
| 下载报告 | 质量报告 PDF |
| 下载参数 | 这次任务实际用过的参数 |
| 评估 | 用 GPS 比平面偏差，按拼图像素计 |

成果文件不在网页里整幅下载。页面上的「下载报告」只有 PDF，「查看RGB影像」只有预览图。多光谱原片和整幅正射、DSM 用下面的命令上传、下载。

## 2. 多光谱文件上传和成果下载

命令在自己的电脑上执行（macOS 终端或 Windows PowerShell）。服务器登录：

|  |  |
| --- | --- |
| 地址 | `10.17.19.198` |
| 用户 | `root` |
| 密码 | 由管理员单独提供 |

第一次连接若询问是否信任主机，输入 `yes`。随后输入上面的 SSH 密码。密码输入时屏幕不显示字符。

页面里的 `/data/...` 不能直接拿来 scp。这台机器上对应关系是：

| 页面上看到的路径 | 命令里要写的路径 |
| --- | --- |
| `/data/input/...` | `/home/spectrum-mosaic/server/data/input/...` |
| `/data/output/...` | `/home/spectrum-mosaic/server/data/output/...` |

不要传到根目录下的 `/data`。那块盘已经快满，拼图数据在 `/home`。

### 上传多光谱原片

把整夹航片传到一个新目录，不要覆盖服务器上已有的 `S810原始数据` 或 `MAX_20251017`。目录名自定，下面用 `试用测区`。

macOS / Linux：

```bash
rsync -avP "./试用测区/" root@10.17.19.198:/home/spectrum-mosaic/server/data/input/试用测区/
```

没有 `rsync` 时用：

```bash
scp -r "./试用测区" root@10.17.19.198:/home/spectrum-mosaic/server/data/input/
```

Windows PowerShell：

```powershell
scp -r ".\试用测区" root@10.17.19.198:/home/spectrum-mosaic/server/data/input/
```

传完后，在「新建处理」里把输入目录填成页面路径，不是上面的 `/home` 路径：

```text
/data/input/试用测区
```

输出目录填：

```text
/data/output/runs/试用测区
```

航片保持原来的文件夹结构一起传。支持 JPG、TIFF。只传某一张照片、或把文件散落在 `input` 根上，任务认不出架次。

## 4. 如果要自己提一条任务

确认列表里没有「运行中」的任务，再提交。

1. 打开「新建处理」。
2. 选择已有的 S810 处理方案，或先按第 2 节把自己的航片传到服务器。页面里的输入、输出仍填 `/data/input/...` 和 `/data/output/runs/...`，不要填自己电脑上的路径，也不要填 `/home/...`。
3. 内存、CPU、GPU 保持方案里的值。选了 GPU 不表示每一步都在用显卡，见第 4 节。
4. 点「开始处理」。系统会在输出目录下新建一个时间戳子目录，不会覆盖上一次成果。
5. 回到「处理记录」。运行中的任务可点「监控」看进度和日志，或点「任务详情」看当前走到哪一步。

S810 全分辨率、8 个波段，最近一次大约 2 小时：空三约 46 分钟，密集匹配约 18 分钟，彩色正射约 6 分钟，七个光谱波段正射约 57 分钟。进度条按阶段等权，不是按剩余时间，正射后半段会停在同一百分比比较久，这是正常的。

不要对正在跑的任务点「立即停止」或「删除」。停掉后当前这一步没写完的成果不会保留。

## 5. 关于 GPU

任务详情里的「任务 GPU」是提交时选的卡。S810 上测过两处：像对匹配、正射贴图。开 GPU 都比 32 个 CPU 核更慢，所以正式计算走 CPU。多光谱正射那几十分钟是 CPU 在做拼接线，不是显卡在算。

对照说明见同目录《GPU为何未缩短时间》。25 分钟是客户现场 RTX 4090 上的目标，这台试用机是 Tesla T4，不能把这里的耗时当成 4090 的成绩。

## 6. 试用时不要做的事

- 不要删除或停止别人正在跑或已经成功的任务。
- 不要在「处理方案」「系统配置」里改参数后再提交。
- 不要同时开第二条任务。
- 不要把「查看RGB影像」里下载的预览图当成交付用的整幅正射。整幅正射、各光谱波段和 DSM 用第 2 节的命令下载。
- 不要把航片传到 `/data`，也不要覆盖 `S810原始数据`、`MAX_20251017`。
