版本 1.0。本文给试用人员使用：先把航片传到服务器，再新建处理方案，然后新建处理，最后查看和下载正射、DSM。

用电脑上的 Chrome 或 Edge 打开。电脑需要能访问内网 `10.17.19.198`。手机上看不清大图，也不适合做验收。

网页登录账号：

| 密码 | `zdrh@123456` |

这个账号下已经有两套处理方案，登录后可直接选用：

## 1. 建议的试用顺序

一次全分辨率、多光谱的处理大约两小时。试用按下面三步做。不要新建方案，也不要改方案里的波段和算法参数。

1. 用 SSH 把数据集上传到服务器上的新目录。网页不能直接上传整夹航片。
2. 打开「新建处理」，选择「标准全波段」。只要彩色时改选「RGB 快速预览」。
3. 确认「测区数据」是 `/data/input/S810原始数据/20260528原始数据/预处理-辐射+JPG/1530`，把「成果目录」改成自己的输出目录，然后点「开始处理」。

任务成功后，在「处理记录」里看拼图、质量报告，并下载正射和 DSM。需要改某一块用哪张照片时，用「拼接线处理」。有野外检测点时，用「精度验收」。

同一时间只能跑一条任务。已有任务在排队或运行时，「开始处理」会变成「已有任务运行中」。

## 3. 一次处理在做什么

提交之后，任务按七步走完：

| 步骤 | 名称 | 这一步产生什么 |
| --- | --- | --- |
| 1 | 输入输出 | 确认读哪里、写到哪里，并建好本次输出目录 |
| 2 | 影像编目 | 清点航片，去掉白板、贴地、倾角过大的废片 |
| 3 | 空三解算 | 求出每张照片的位置、朝向和稀疏地面点 |
| 4 | 密集匹配 | 在重叠区域估计地面高程 |
| 5 | DSM 生成 | 去掉尖刺、补小洞，写出地形 |
| 6 | 正射镶嵌 | 按地形把照片压到地图上，拼成各波段正射 |
| 7 | 质量报告 | 汇总精度与覆盖，写出 PDF |

成果在本次输出目录的 `拼图结果/` 里。彩色正射是 `Orthomosaic_pix_surf_group0.tif`，其余波段按波长从小到大排 `group1`、`group2`……地形是 `DSM.tif`。质量报告 PDF 在输出目录下，不在 `拼图结果` 里面。

以已有的 S810 成果为例，波段对应关系是：

| 文件 | 内容 |
| --- | --- |
| `Orthomosaic_pix_surf_group0.tif` | 彩色正射 |
| `Orthomosaic_pix_surf_group1.tif` | 450nm |
| `Orthomosaic_pix_surf_group2.tif` | 550nm |
| `Orthomosaic_pix_surf_group3.tif` | 650nm |
| `Orthomosaic_pix_surf_group4.tif` | 720nm |
| `Orthomosaic_pix_surf_group5.tif` | 750nm |
| `Orthomosaic_pix_surf_group6.tif` | 800nm |
| `Orthomosaic_pix_surf_group7.tif` | 850nm |
| `DSM.tif` | 地形 |

别的测区波长不同时，彩色仍是 `group0`，其余仍按波长从小到大编号。

## 4. 第一步：用 SSH 上传数据集

网页不能直接上传整夹航片。先在自己的电脑上执行下面的命令，把数据集传到服务器，再去做处理方案。

命令在自己的电脑上执行（macOS 终端或 Windows PowerShell）。

|  |  |
| --- | --- |
| 地址 | `10.17.19.198` |
| 用户 | `root` |
| 密码 | 由管理员单独提供 |

第一次连接若询问是否信任主机，输入 `yes`。密码输入时屏幕不显示字符。

页面上的 `/data/...` 不能直接拿来做上传路径。这台机器上的对应关系是：

| 页面上填写的路径 | 命令里要写的路径 |
| --- | --- |
| `/data/input/...` | `/home/spectrum-mosaic/server/data/input/...` |
| `/data/output/...` | `/home/spectrum-mosaic/server/data/output/...` |

不要传到根目录下的 `/data`。拼图数据在 `/home`。

把整夹航片传到一个新目录。不要覆盖服务器上已有的 `S810原始数据` 或 `MAX_20251017`。目录名自定，下面用 `试用测区`。航片保持原来的文件夹结构一起传。支持 JPG、TIFF。只传某一张照片，或把文件散落在 `input` 根上，任务认不出架次。

macOS / Linux：

```bash
rsync -avP "./试用测区/" root@10.17.19.198:/home/spectrum-mosaic/server/data/input/试用测区/
```

没有 `rsync` 时：

```bash
scp -r "./试用测区" root@10.17.19.198:/home/spectrum-mosaic/server/data/input/
```

Windows PowerShell：

```powershell
scp -r ".\试用测区" root@10.17.19.198:/home/spectrum-mosaic/server/data/input/
```

传完后记下页面上要填的路径。下一步写进处理方案，不要填自己电脑上的路径，也不要填 `/home/...`：

```text
输入测区目录：/data/input/试用测区
输出目录：/data/output/runs/试用测区
```

成果下载放在任务成功之后。优先在网页里下载。文件很大、浏览器中断时，再用本节末尾的命令取整目录。

打开该任务的「任务详情」，复制「输出」一栏，把开头的 `/data` 换成 `/home/spectrum-mosaic/server/data`。例如页面上是：

```text
/data/output/runs/试用测区/20261109_153000
```

命令里就是：

```text
/home/spectrum-mosaic/server/data/output/runs/试用测区/20261109_153000
```

```bash
rsync -avP root@10.17.19.198:/home/spectrum-mosaic/server/data/output/runs/试用测区/20261109_153000/拼图结果/ "./拼图结果/"
```

时间戳以任务详情里的输出路径为准。不要沿用别人任务的目录。

## 5. 第二步：新建处理

数据集传完后再做这一步。先确认「处理记录」里没有状态为「排队」或「运行中」的任务。账号里已有的两套方案直接用，不要新建，也不要改里面的波段、格网和套色。

| 方案 | 什么时候选 |
| --- | --- |
| 标准全波段 | 彩色和各光谱波段都要。预设是「通用」，不锁参考格网，不做调试套色 |
| RGB 快速预览 | 只看彩色正射，确认几何和接缝。预设是「RGB 快速预览」，只出 Color |

1. 打开「新建处理」。
2. 「标题」可留空。留空时系统用任务号和时间命名。
3. 「处理方案」按上表选择。测区数据会带出 S810 这一层，不要改成别的目录，也不要清空。
4. 确认「测区数据」是 `/data/input/S810原始数据/20260528原始数据/预处理-辐射+JPG/1530`。「成果目录」改成 `/data/output/runs/试用测区`。系统会读取原始分辨率。
5. 「降低分辨率」：试用交付用「不降低」。选「降低到 1/2」或「降低到 1/4」会把像元放大、出图更快，但不是全分辨率成果。若页面写着「已锁定交付格网」，则按锁定的格网出图，这里的倍数不生效。
6. 内存、CPU、GPU、显存保持方案带出的值，不要改。
7. 展开「方案参数摘要」只作核对。调试套色应为关，调试对照目录应为空。
8. 点「开始处理」。

系统会在成果目录下新建一个时间戳子目录，不会覆盖上一次成果。提交成功后，右侧「处理进度」出现任务号和状态。也可以回到「处理记录」查看。

进度条按七个阶段等权，不是按剩余时间。正射镶嵌后半段会停在同一百分比比较久，这是正常的。S810 全分辨率、8 个波段，最近一次大约 2 小时；自己的测区张数和波段不同，耗时也会不同。选了 GPU 不表示每一步都在用显卡，像对匹配走 CPU。

不要对正在跑的任务点「立即停止」或「删除」。立即停止后，当前这一步还没写完的部分不会保留；已经写完的 DSM 和正射会留下。

运行中可用的控制（都在该行「操作」→「运行」，或执行页右上角）：

| 按钮 | 什么时候用 |
| --- | --- |
| 监控 | 打开执行页，看进度和日志 |
| 暂停 | 当前阶段跑完再停。之后点「继续运行」，不新开输出目录 |
| 继续运行 | 从暂停处接着跑 |
| 继续 | 状态是「等待继续」时，进入下一阶段 |
| 立即停止 | 马上结束进程。试用时不要对别人的任务使用 |
| 失败重试 | 失败后从失败处重试，不新开输出目录 |
| 清理并续跑 | 仅在进度卡住、页面提示进程已退出时使用。正常计算中不要点 |

任务失败时，先打开「任务详情」看日志里停在哪一步，再联系管理员。不要改方案后反复提交。

## 6. 查看成果和下载

在「处理记录」里：

1. 可用任务号、状态、阶段、处理方案、日期和关键字筛选。状态选「成功」。
2. 点该行最右侧「操作」。
3. 按需要点下面的入口。

| 操作 | 能看到什么 |
| --- | --- |
| 任务详情 | 七步流程、每步耗时、输入输出路径、运行日志。点「正射镶嵌」可看彩色和各光谱波段各花了多久 |
| 拼图影像 | 按波段看整幅拼图，可拖动、缩放，并可下载该波段的 GeoTIFF |
| 质量报告 → 查看 | 打开汇总页，也可在页内翻阅 PDF。这里的照片定位差来自空三，不是野外检测点 |
| 质量报告 → 下载 | 把质量报告 PDF 下载到自己的电脑 |
| 下载 → 处理参数 | 这次任务实际用过的参数 |
| 下载 → 拼图原文件 | 把各波段正射和 DSM 打成一个 zip 下载 |
| 精度验收 | 在拼图上选检测点，填写野外坐标后评估 |
| 监控 | 任务还在跑时，打开执行页看进度和日志 |

列表里的 RGB 小图只用于辨认任务。交付用的整幅正射、各光谱波段和 DSM，用「拼图原文件」或拼图页里的下载。

在「拼图影像」页还可以：

- 用「波段」切换彩色和各光谱波段。
- 「下载当前波段原文件」只下当前这一幅 GeoTIFF，按钮上会标出文件大小。
- 「下载全部文件」包含各波段正射、DSM 和质量报告。

看完点「返回记录」。文件很大、浏览器下载中断时，用第 4 节的命令到任务详情里的输出目录取 `拼图结果/`。

## 7. 质量报告

任务成功后，在「操作」→「质量报告」点「查看」。

页内可以在「汇总」和「PDF」之间切换。汇总里能看到空三、DSM、正射和各相机的统计，以及正射、DSM、相机位置、空三、重叠度等图。点「下载」得到 PDF 文件。

报告里的「特征点」是每张照片上提取的纹理位置。「连接点」是多张照片对上之后的点，不是特征点本身。照片定位差来自空三解算，不能代替第 8 节的野外检测点。

## 8. 精度验收

有野外实测坐标时再做。没有野外点时，看质量报告即可。排队中的任务不能验收。

1. 在成功任务的「操作」里点「精度验收」。
2. 确认「最少点数」「最多点数」和「平均位置误差上限」。默认是 20 到 30 个点，平均误差须小于 2 像素。改完后点击输入框以外的位置，设置会保存。
3. 「基准波段」选用来选点的正射，一般用彩色。
4. 「野外坐标系」：经纬度选 `EPSG:4326`；若野外坐标已经是拼图所用的投影坐标，选页面列出的另一项。
5. 保持「添加检测点」。在大图上单击地面明显地物。左侧小图只用于跳转，不用于加点。按住拖动可平移，滚轮或「放大」「缩小」可缩放。
6. 在下方表格填该点的野外经度、纬度（或东、北坐标）。点到别的格子时，这一格会保存。
7. 点数落在最少和最多之间后，点「评估校验」。

结果分条显示「满足」「不满足」「未完成」或「未评估」。像素误差是拼图坐标与野外坐标的平面距离，除以基准波段的地面分辨率，再对各点取平均。

点选错了：先在表里点中该行，再点「移动选中点」，然后在大图上点新位置。不需要的点在该行点「删除」。

## 9. 拼接线处理

某一块地面想改用另一张重叠照片时用这一节。来源任务的文件不会被改掉。系统复制成果，生成一条带「拼接线」标记的新记录。

1. 打开「拼接线处理」。
2. 点「新建拼接线处理」，选择一条已经成功、且本身不是拼接线任务的任务号，点「创建」。
3. 在新记录上点「处理」。
4. 用「放大」「缩小」「适应」看图。在图上拖动可平移。
5. 点一块自动色块，右侧列出能拍到这块的照片。点另一张，即可换成这张。
6. 若要自己圈范围：点「绘制范围」，在图上依次点击，至少 3 个点后点「闭合」。画错可「撤销一点」或「取消绘制」。
7. 确认右侧「已用于这块」的照片无误后，点「重算」。没改过时「重算」不能点。
8. 回到「处理记录」等这条新任务成功，再按第 6 节下载。

「放弃修改」会丢掉尚未出图的手工选择。已经按手工范围出过图时，会再出一版软件自己选的结果。任务正在跑时不能进入处理界面。

## 10. 航片分批到达

只有管理员已经安排「按测区持续收片」时才用「测区管理」。普通一次试用走第 4、5 节，不要在这里新建测区。

测区建立后，正式目录和输出根目录不能再改。收件区是正式目录后面加 `.inbox` 的那个路径，页面「上传命令」可以复制。

1. 打开「测区管理」，点该测区的「进入」。
2. 把新航片按页面上的命令传到收件区。同一曝光号的新片子、或后到的新波长，都传到收件区，不要直接丢进正式目录。
3. 同一个文件连续两次扫描大小不变，才算传完，并拷进正式目录。可点「立即扫描入库」，或等页面上的扫描间隔。
4. 「入库后自动拼」打开时，新航片入库后会在这一条任务上开始拼图。关掉时只入库，数据齐了再点「在当前任务上拼图」。
5. 别的任务还在跑时，新文件可以入库，这条任务要等它结束后再开始。正在拼的时候不会另开第二条。

曝光列表里：「上传中」表示文件还在变大，「已传完」表示可以入库，「已入库」表示已经进入正式目录。

删除测区只会删掉这条记录，正式目录、收件区和已有成果文件都还在。试用时不要删。

## 11. 查看单张影像

「影像查看」用来核对某一张 TIF 或 JPG，不参与拼图。

把文件拖进页面。可以看元数据、波段和点击位置的像元值。大图是抽样预览，不是整幅原分辨率浏览。

## 12. 试用时不要做的事

- 不要删除、停止或「清空全部」别人正在跑或已经成功的任务。删除只从列表移除记录，成果目录仍留在服务器上，但试用账号不应做这件事。
- 不要修改「标准全波段」和「RGB 快速预览」里的算法参数，也不要新建方案，不要改「系统配置」。提交任务时测区数据保持 S810 的 1530 目录，只改成果目录。
- 不要同时开第二条任务。
- 不要把航片传到主机根目录的 `/data`，也不要覆盖 `S810原始数据`、`MAX_20251017`。
- 不要把列表里的 RGB 小图当成交付用的整幅正射。
- 没有管理员安排时，不要新建测区，不要打开「入库后自动拼」。
- 进度正常前进时，不要点「清理并续跑」或「立即停止」。
