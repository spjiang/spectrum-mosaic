# 自研摄影测量管线 架构设计

> 目标：不依赖 ODM / Metashape / Pix4D 的通用摄影测量管线。GSD、覆盖、坐标系由当次航摄 POS/相机估计，不写死某一测区。  
> 自研边界：算法与管线全部自己实现；底层只用通用数值与图像库（numpy / scipy / OpenCV / rasterio），不调用成品摄影测量软件。  
> 验收：商业 `拼图结果/` 只当尺子（`--benchmark-dir` 写比对报告），不改出图。算法调好后，同一测区不传该参数也应得到同等成果。  
> 日期：2026-09-19

## 2. 本批数据的硬约束（实测）

| 事实 | 值 | 影响 |
| --- | --- | --- |
| 影像尺寸 | RGB 与 MS 均 **2048 × 1536** | 与报告里的 S800（1440×1080）不同代，内参需重标 |
| 位深 | RGB 8bit / MS **uint16** | 融合与输出需分别处理 |
| XMP 主点 | `720, 540` | 是 1440×1080 的中心，**对本数据是过期默认值** |
| XMP 畸变 | `0,0,0,0,0` | **厂家未给**，必须自标定 |
| 平均 AGL | 111.8 m（109.1–115.0） | 相对起飞点，非真实离地高 |
| 绝对航高 | 1871.5 m | |
| **地形高程** | **1635.5 – 1830.2 m，p1–p99 起伏 161 m** | **真实离地高在 41–236 m 之间变化，GSD 差 6 倍** |
| 姿态 | pitch ≈ -89.2°，roll ≈ -1.0° | 近正下视 |
| Yaw | 出现 **-516.8°** 异常值 | 必须归一化并做鲁棒处理 |
| RTK | `RtkUsage=0`，平面 3 m / 高程 5 m | 绝对精度上限 |
| 影像数 | 671 RGB + 668×7 MS + 2×7 白板 | 3 个曝光缺 MS，按 UUID 对齐 |

### 2.1 这解释了「拼接完全不对」

地形起伏 161 m，而航高只有 111.8 m。把地面当水平面时，单点最大投影位移：

```
Δ = r · Δh / H   →  1024 px × 161 m / 111.8 m ≈ 1474 px
```

即像幅边缘可错位 **1474 像素（约 79 米）**。这不是精度问题，是方法不成立。**DSM 不是加分项，是本数据的必要条件。**

## 3. 管线设计

```text
输入 MAX_20251017_001/（只读）
  │
  ├─[1] catalog  文件识别 / POS / 波段 / UUID / 白板与倾角过滤
  │
  ├─[2] features RootSIFT（主波段=RGB），分块提取，每片上限 8192
  │
  ├─[3] pairs    POS 足迹重叠预筛，O(N·k) 取代 O(N²)
  │
  ├─[4] matching FLANN kNN + Lowe ratio + 交叉校验 + 本质矩阵 RANSAC
  │
  ├─[5] tracks   并查集构连接点轨迹，剔除冲突轨迹
  │
  ├─[6] at       POS 初始化外方位 → 多视前方交会 → GNSS 约束光束法平差
  │              （Schur 补 + 稀疏 LM，自标定 f,cx,cy,k1,k2,k3,p1,p2,b1,b2）
  │              → 波段间刚体关系 (RigRelatives) 一次解算
  │
  ├─[7] dense    物方多视平面扫描 MVS（NCC/Census + 半全局代价聚合）→ 2.5D 高程场
  │
  ├─[8] dsm      中值滤波 + 空洞填充 + 输出 DSM（GSD = 正射 ×2）
  │
  ├─[9] ortho    真正射：DSM 每格反投影到各影像，Z-buffer + 角度法遮挡检测
  │              → 每格得到「可见影像候选集 + 灰度」
  │
  ├─[10] seamline 图割能量最小化选标签（颜色差 + 梯度 + 星下点距离 + 高程）
  │
  ├─[11] blend    增益曝光补偿 + 拉普拉斯金字塔多频段融合（多光谱禁用色彩校正）
  │
  ├─[12] products 8 张正射 + DSM + KML + 伪彩色 + 拼接线 GeoJSON
  │
  └─[13] report   自研 PDF（章节对齐样例报告，署名单引擎）+ JSON + 明码日志
```

## 4. 各环节的业界算法选型与依据

### 4.1 特征提取（features）

- **RootSIFT**：Arandjelović & Zisserman, CVPR 2012。SIFT 描述子做 L1 归一化后开方，Hellinger 距离等价欧氏距离，检索精度显著优于原始 SIFT，且零额外成本。业界（COLMAP、OpenSfM）默认。
- 分块提取保证特征空间分布均匀，避免纹理富集区吃满配额（报告里「影像关键点数最大值 8192」说明 LiMapper 也做了上限截断）。
- MS 影像 uint16 → 分位数拉伸到 8bit 再提特征。

### 4.2 像对筛选（pairs）

- 用 POS + 概略地形高，投影四角得地面足迹多边形，按 IoU / 重叠比排序取前 k 个邻居。
- 依据：GNSS/INS-Assisted SfM, Remote Sens. 2020, 12(3):351 —— 用轨迹先验替代词袋检索，长条带数据尤其有效。
- 671 帧 × k=12 ≈ 8000 像对，相比全组合 22.5 万对降低 28 倍。

### 4.3 匹配与几何校验（matching）

- FLANN kd-tree kNN(k=2) + Lowe ratio 0.8 + 互为最近邻交叉校验。
- 已知内参近似值 → 本质矩阵 RANSAC（5 点法，Nistér 2004），阈值按像素折算。
- 平面退化检测：同时拟合单应，若单应内点率接近本质矩阵内点率则判平面场景，改用单应内点。

### 4.4 空中三角测量（at）

采用 **GNSS/INS 全辅助 SfM**，而非经典增量式 SfM。依据：

- Remote Sens. 2020, 12(3):351 —— 有 GNSS/INS 时直接用其作外方位初值，跳过增量重建，稳定性与速度均优。
- Remote Sens. 2021, 13(21):4222 —— 长条带弱结构会产生「碗状变形」，需 GNSS 约束平差 + 渐进释放畸变参数。
- JSTARS 2024 —— 单条带无 GCP 的 POS 辅助空三误差改正模型。

平差目标函数：

```
min Σ_ij ρ( ‖ π(K_c, D_c, R_i, t_i, X_j) − x_ij ‖² )          重投影项（Huber 核）
  + Σ_i  ‖ (t_i − t_i^GPS) / σ_xyz ‖²                          GNSS 位置先验（σ=3,3,5 m）
  + Σ_i  ‖ Log(R_i^T R_i^IMU) / σ_rpy ‖²                       IMU 姿态先验（弱权）
  + Σ_c  ‖ (θ_c − θ_c^0) / σ_θ ‖²                              内参正则（抑制碗状变形）
```

- 相机模型 Brown-Conrady + b1/b2 仿射项，与报告的 `f, cx, cy, k1, k2, k3, b1, b2, p1, p2` 完全一致。
- 稀疏求解：Schur 补消去 3D 点块 + 稀疏 Cholesky，等价 Ceres 的做法。先用 `scipy.optimize.least_squares(jac_sparsity=...)` 跑通，再换自写 Schur LM 提速。
- 外点：残差 > 6 px（与报告一致）剔除后重平差，迭代至收敛。
- **波段刚体约束**：同一曝光的 8 个相机共享一个平台位姿，各相机相对平台的 `(R_rig, t_rig)` 全局只有 8 组未知数。这把外参数量从 8N 降到 N+8，是多光谱平差的关键，也直接实现 REQ-04-01 的「主波段重建 + 其余配准」。

### 4.5 密集匹配与 DSM（dense / dsm）

- 报告写明「类型 2.5D」，因此采用**物方平面扫描**而非像方视差：直接在 DSM 格网上对每个 (X, Y) 沿 Z 扫描，把候选高程投影到所有可见影像，用 Census/NCC 多视代价聚合，取代价最小的 Z。
- 优点：直接产出 2.5D 高程场，无需点云融合；天然多视；易并行。
- 代价聚合用 SGM 式半全局路径优化（Hirschmüller, PAMI 2008），8 方向动态规划，抑制噪声。
- 后处理：搜索窗贴边作废 → 中值去尖 → 3 格中值平滑 → 空洞调和插值。
- 分层：先 4 倍 GSD 粗格网、由稀疏点起伏估计的半宽定位，再成品格网、不少于 ±4 m 精化（Gallup et al., CVPR 2007）。半宽取 p90−p10 的 1/4（8–48 m），不写死某测区的 12/24 m。

### 4.6 真正射（ortho）

- 遮挡检测采用 **Z-buffer + 角度法（angle-based ray tracing）双保险**。依据：Habib et al., Remote Sens. 2018, 10(4):581 —— 角度法对 DSM 格网间距不敏感，优于纯 Z-buffer；配合 occlusion extension 与 radial section overlap 抑制假可见。
- 最大倾斜角 60°（与报告一致）：视线与天顶夹角超阈值的影像不作为该格候选。

### 4.7 拼接线（seamline）

- 图割能量最小化。依据：Li et al., ISPRS JPRS 2016, 113:1-16；Chen et al., Remote Sens. 2014, 6(12):12334（引入 DSM 高程避免缝穿建筑）。
- 能量项：
  - 数据项 = 该格到候选影像星下点的距离（越近越优）+ 倾斜角惩罚；
  - 平滑项 = 相邻格在两候选影像间的颜色差 + 梯度差 + 归一化 DSM 高程差。
- 用 PyMaxflow（Boykov-Kolmogorov）做 α-expansion 多标签求解。
- 输出拼接线矢量 GeoJSON（REQ-03-05）。

### 4.8 融合（blend）

- 曝光补偿：Brown & Lowe, IJCV 2007 的增益补偿——重叠区均值一致性最小二乘解每帧增益。**多光谱通道禁用**（保辐射真值，与报告「颜色校正：禁用」一致），仅 RGB 启用。
- 多频段融合：Burt & Adelson, ACM TOG 1983 拉普拉斯金字塔。「融合层级 中」对应 5 层。
- 沿拼接线做带宽自适应的过渡带，消除接缝跳变。

## 5. 与商业成品的比对验收（compare）

`compare.py` 对每项产出量化打分，这是「测试结果与商业结果匹配」的硬指标：

| 指标 | 方法 | 目标 |
| --- | --- | --- |
| 地理范围 / 原点 | 与商业 GeoTIFF transform 逐元素相等 | 差 < 1e-4 m |
| GSD | `transform.a` | 差 < 1e-9 m |
| 宽高 / tiled / 压缩 / nodata | 文件 profile | 必须相同 |
| DSM 高程 | 同一格网逐像元 | 见 `比对报告.txt` |
| 正射覆盖 / RGB | 同一格网逐像元 MAE、相关系数 | 见 `比对报告.txt` |

全量跑完必须写出 `比对报告.txt`。算法出处见 [算法出处.md](算法出处.md)。

DSM 高程中误差、正射平面偏移、接缝质量等数值门槛以 `比对报告.txt` 为准。

输出并排对比图写进 `compare/` 目录。
